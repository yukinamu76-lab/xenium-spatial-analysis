# Probe-based single-cell transcriptomic analysis of peripheral blood neutrophils

## Sample preparation and library generation
Whole blood samples were collected from the hearts of PBS- or albumin-treated 4T1-bearing mice using heparin-coated syringes (heparin-Na, 1000 U/ml; nacalai tesque) on day 10 after 4T1 transplantation. Neutrophils were enriched in whole blood samples using the Neutrophil Isolation Kit, mouse (Miltenyi Biotec, Bergisch Gladbach, Germany) following the manufacturer’s protocol. The enriched cell suspensions were centrifuged at 400 × g for 5 min, and the resulting cell pellets were resuspended and fixed in 500 μL of fixation buffer provided by CyberomiX (Kyoto, Japan). Fixed samples were subsequently submitted to CyberomiX for probe-based single-cell transcriptomic analysis.
Four biological samples were analyzed, comprising two PBS-treated and two albumin-treated 4T1-bearing mice (PBS-1, PBS-2, Alb-1, and Alb-2), with a target recovery of 10,000 cells per sample. Libraries were prepared using the GEM-X Flex workflow (10x Genomics, Pleasanton, CA, USA), including the GEM-X Flex Sample Preparation v2 Kit (PN-1000781), GEM-X Flex Gene Expression Mouse n-plex, 64 samples (PN-1000831), GEM-X Flex Gene Expression Chip Kit, 4 Chips (PN-1000791), and Dual Index Kit TS Set A (PN-1000251), together with the Chromium Mouse Transcriptome Probe Set v1.1.1.
Each sample was labeled with a unique Sample Barcode before pooling for multiplexed library preparation. Sample Barcode assignments were PBS-1, BC001; PBS-2, BC002; Alb-1, BC003; and Alb-2, BC004. Sequencing was performed by CyberomiX on a NovaSeq X Plus system with 54-bp Read 1 and 50-bp Read 2. FASTQ files were processed using Cell Ranger multi (version 9.0.1; 10x Genomics) with the 10x Genomics prebuilt mouse reference refdata-gex-GRCm39-2024-A. Reads were demultiplexed to their sample of origin based on Sample Barcode information, and the resulting per-sample filtered feature-barcode matrices were used for downstream analyses.

## Single-cell data processing and quality control
Per-sample filtered feature-barcode matrices generated by Cell Ranger were imported into Seurat (version 5). Seurat objects were created with min.cells = 3, thereby removing genes detected in fewer than three cells. Mitochondrial transcript content was calculated using genes beginning with mt-. Cells were retained when they satisfied 200 < nFeature_RNA < 6,000 and percent.mt < 15%, after which the four samples were merged into a single Seurat object. Sample-level cell numbers before and after quality-control filtering are provided in Table EV6.
Counts were log-normalized using NormalizeData. The 2,000 most variable genes were selected using FindVariableFeatures with the vst method, and expression values were scaled using ScaleData while regressing out percent.mt. Principal-component analysis was performed with 30 principal components. The four samples were integrated using Harmony with sample_id as the grouping variable to obtain a shared low-dimensional representation for clustering and visualization. A shared nearest-neighbor graph was constructed using Harmony dimensions 1–15, followed by Louvain community detection with FindClusters at a resolution of 0.6. UMAP was calculated using the same Harmony dimensions.

## Cell-type annotation and neutrophil selection
Cell types were assigned based on canonical immune-cell marker expression visualized with Seurat DotPlot and FeaturePlot. Marker-gene panels used for the initial cell-type annotation are provided in Table EV7, and pre- and post-annotation UMAPs are shown in Fig. EV4A. For visualization in Fig. EV4A, cells were randomly downsampled to 10% of the full dataset; cell-type annotation and all downstream quantitative analyses were performed using the full dataset. Clusters expressing canonical neutrophil markers, including S100a8, S100a9, Ly6g, Itgam, Csf3r, and Cxcr2, were retained as neutrophils. Non-neutrophil populations, including monocytes, NK cells, plasmacytoid dendritic cells, and basophils, were excluded before neutrophil-specific analyses. Sample-level neutrophil cell numbers and their proportions among quality-control-filtered cells are provided in Table EV6.
The neutrophil population was subsequently subset and reprocessed independently. Neutrophil cells were log-normalized, the 2,000 most variable genes were selected using the vst method, and expression values were scaled with regression of percent.mt. PCA with 30 components was repeated, followed by Harmony integration using sample_id as the grouping variable to obtain a shared low-dimensional representation for neutrophil clustering and visualization. Clustering was performed using Harmony dimensions 1–15 at a resolution of 0.6, and UMAP was calculated using the same Harmony dimensions, yielding 11 neutrophil subclusters (clusters 0–10). Cell numbers and relative proportions of clusters 0–10 in each sample are provided in Table EV6. The top 10 marker genes for each neutrophil subcluster are provided in Table EV8.
Clusters 9 and 10 were excluded before downstream neutrophil-state analyses. Cluster 9 showed a mitochondrial-transcript-dominant marker profile and relatively elevated mitochondrial transcript content compared with the other neutrophil clusters (Fig. EV4B and Table EV8). Cluster 10 showed reduced expression of canonical neutrophil markers together with expression of non-neutrophil lineage markers, including T-cell-, NK-cell-, and mast-cell-associated genes (Fig. EV4C and Table EV8). Marker-gene panels used to assess neutrophil-subcluster purity are provided in Table EV7. The remaining nine clusters (clusters 0–8) were retained for downstream neutrophil-state analyses.
For visualization of treatment-group differences in neutrophil-cluster composition (Fig. 6B), cells from the two biological replicates within each treatment group were pooled, the proportion of neutrophils belonging to each cluster was calculated within each treatment group, and the albumin-to-PBS ratio of these proportions was determined for each cluster. Sample-level cluster cell numbers and proportions are provided separately in Table EV6.

## Pre-ranked gene lists and comprehensive gene set enrichment analysis
For each retained neutrophil cluster (clusters 0–8), gene expression was compared with all other retained neutrophil clusters using Seurat FindMarkers. Clusters 9 and 10 were excluded both as target clusters and from the comparison background. No minimum fold-change or detection-rate thresholds were applied (logfc.threshold = 0, min.pct = 0), and all detected genes were ranked in descending order according to avg_log2FC. Differential expression statistics were calculated using the Wilcoxon rank-sum test implemented in Seurat. These ranked lists, rather than significance-filtered differentially expressed gene sets, were used as GSEA inputs.
Pre-ranked GSEA was performed using fgseaMultilevel. Mouse gene sets were obtained from MSigDB through msigdbr and included the Hallmark, Gene Ontology Biological Process (GO BP), and Reactome collections. A minimum gene-set size of 10 was used. The maximum gene-set size was 500 for Hallmark and 1,000 for GO BP and Reactome; eps = 0 was used. Enrichment was summarized using normalized enrichment scores (NES) and FDR-adjusted P values returned by fgsea. Complete results for clusters 0–8 are provided in Dataset EV7.

## Targeted GSEA for representative neutrophil programs
To directly compare representative transcriptional programs across clusters 2, 6, 7, and 8, targeted pre-ranked GSEA was additionally performed for five MSigDB gene sets: HALLMARK_E2F_TARGETS, GOBP_MITOTIC_CYTOKINESIS, HALLMARK_INTERFERON_ALPHA_RESPONSE, HALLMARK_INTERFERON_GAMMA_RESPONSE, and GOBP_REGULATION_OF_GRANULOCYTE_CHEMOTAXIS. fgseaMultilevel was run with minSize = 10, maxSize = 500, eps = 0, and nPermSimple = 100,000. Raw P values from the 20 cluster–gene-set combinations (five gene sets × four clusters) were jointly adjusted using the Benjamini–Hochberg method; these globally adjusted FDR values were used for the significance assessment shown in Fig. 6C.

## Selection and visualization of the broader GSEA landscape
For Fig. EV4E, representative pathways were selected from the complete GSEA results across clusters 0–8 for compact visualization while retaining all pathways in Dataset EV7. Pathways were assigned to eight neutrophil-relevant functional categories: cell cycle, interferon response, innate immunity, migration and chemotaxis, metabolism, RNA processing and translation, cellular stress and protein homeostasis, and signal transduction and cell fate. Tissue-specific/developmental terms and overly generic pathway terms were excluded from representative-pathway selection but were retained in the complete results.
Within each functional category, candidate pathways were prioritized using a predefined composite score integrating statistical significance (weight 0.30), enrichment magnitude (0.30), cluster specificity (0.25), rarity of enrichment across clusters (0.10), and gene-set interpretability (0.05). Pathways used for significance marking in the heatmap satisfied FDR < 0.05 and |NES| ≥ 1.5. Cell-cycle and interferon-response pathways were displayed in a manually defined biological order, whereas pathways in the remaining functional categories were ordered by hierarchical clustering of their NES profiles across clusters using Spearman correlation-derived distances and complete linkage. This ordering affected visualization only and did not alter NES or FDR values.

## Pseudotime analysis
To characterize transcriptional relationships among neutrophil states, clusters 9 and 10 were removed before trajectory inference, and pseudotime analysis was performed on clusters 0–8 using Slingshot. The two-dimensional UMAP coordinates of the retained neutrophils were used as the reduced-dimensional representation, with neutrophil subcluster identities supplied as cluster labels. No starting or terminal cluster was specified (start.clus = NULL, end.clus = NULL), allowing Slingshot to infer lineage structure and principal curves in an unsupervised manner. Pseudotime values were calculated for individual cells, and cluster-level mean and median pseudotime values were summarized. The Lineage 1 curve corresponding to the trajectory shown in Fig. 6D was overlaid on the UMAP for visualization.

## Software and reproducibility
Upstream sequencing-data processing was performed using Cell Ranger multi (version 9.0.1). Downstream analyses were performed in R (version 4.6.0), primarily using Seurat (version 5), Harmony, fgsea, msigdbr, Slingshot, SingleCellExperiment, dplyr, tidyr, and ggplot2. Random seeds were fixed for reproducibility where stochastic procedures were used (set.seed(1234) in the main single-cell workflow and targeted GSEA, and set.seed(123) in the comprehensive per-cluster GSEA). Analysis code is provided in the accompanying public code repository.
