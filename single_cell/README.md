# Neutrophil single-cell transcriptomic analysis

This directory contains the public-release R code corresponding to **Fig. 6, Fig. EV4, Table EV6–EV8, and Dataset EV7** of the revised manuscript.

The workflow includes Seurat/Harmony preprocessing and clustering, exclusion of neutrophil clusters 9 and 10 before downstream state analyses, the pooled treatment-group calculation used for Fig. 6B, comprehensive and targeted pre-ranked GSEA, joint Benjamini–Hochberg correction across the 20 targeted GSEA tests, and Slingshot pseudotime analysis.

The manuscript-item nomenclature was updated from the former Supplementary Fig./Table numbering without changing the analytical logic or statistical parameters. See `docs/FIGURE_CODE_MAP.md` for the mapping and `docs/CODE_METHOD_AUDIT.md` for the code–Methods audit.

## Data availability

Raw sequencing data are deposited in the DDBJ Sequence Read Archive under accession **DRA031926**. Processed per-sample Cell Ranger filtered feature-barcode matrices are deposited in the DDBJ Genomic Expression Archive (GEA) under accession **E-GEAD-1320**.

See `data/README.md` for the exact expected filenames and input layout.

## Directory structure

- `scripts/scRNA/`: Seurat/Harmony QC, clustering, annotation, composition, marker, DEG-ranking, and pseudotime analyses
- `scripts/gsea/comprehensive/`: cluster 0–8 comprehensive pre-ranked GSEA
- `scripts/gsea/targeted/`: targeted GSEA used for Fig. 6C
- `scripts/gsea/heatmap/`: pathway selection and Fig. EV4E heatmap workflow
- `scripts/reproducibility/`: scripts used to capture the two analysis environments
- `data/README.md`: deposited input-data layout
- `docs/`: Methods, manuscript-item mapping, and code–Methods audit
- `sessionInfo_scRNA.txt`: R/package environment used for the scRNA-seq workflow
- `sessionInfo_GSEA.txt`: R/package environment used for the GSEA workflow
- `PUBLIC_RELEASE_AUDIT.md`: final public-release checks

## Quick start

1. Create a project directory and copy this release into it.
2. Create `Rawdata/` and place the four deposited HDF5 files there exactly as listed in `data/README.md`.
3. Run the scRNA workflow from the repository/project root in numerical order:

```r
source("scripts/scRNA/01_qc_load.R")
source("scripts/scRNA/02_pca_elbow.R")
source("scripts/scRNA/03_clustering_umap.R")
source("scripts/scRNA/04_marker_dotplot_featureplot.R")
source("scripts/scRNA/05_neutrophil_annotation.R")
source("scripts/scRNA/06_neutrophil_subset_pca_elbow.R")
source("scripts/scRNA/07_neutrophil_clustering_umap.R")
source("scripts/scRNA/08_neutrophil_marker_dotplot.R")
source("scripts/scRNA/09_neutrophil_cluster_composition.R")
source("scripts/scRNA/09b_fig6B_pooled_cluster_ratio.R")
source("scripts/scRNA/10_neutrophil_DEG_full_ranking.R")
source("scripts/scRNA/11_neutrophil_trajectory.R")
source("scripts/scRNA/18_supp_all_cell_UMAPs.R")
source("scripts/scRNA/cluster9_10_exclusion_suppfig.R")
```

The comprehensive and targeted GSEA workflows use the rankings generated by `10_neutrophil_DEG_full_ranking.R`. See `docs/FIGURE_CODE_MAP.md` for the relevant GSEA scripts and manuscript outputs.

## Reproducibility

The scRNA-seq and GSEA analyses were performed in separate R environments. Package versions for each analysis are provided in `sessionInfo_scRNA.txt` and `sessionInfo_GSEA.txt`, respectively.

The scRNA-seq environment used **R 4.6.0**, including **Seurat 5.5.0**, **SeuratObject 5.4.0**, **Harmony 2.0.5**, **Slingshot 2.20.0**, and **speckle 1.12.0**. The GSEA environment used **R 4.6.1**, including **fgsea 1.38.0** and **msigdbr 26.1.1**. Full attached and namespace-loaded package information is retained in the corresponding session-information files.

The scripts used to capture these environments are retained under `scripts/reproducibility/`; they do not install or update packages.

No patient identifiers or local absolute filesystem paths are included in this release. Large intermediate RDS objects are not distributed; they are regenerated by the workflow.
